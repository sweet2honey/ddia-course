# 起点：目标是可被追问的权衡陈述，不是读完这本书

用户在 `/teach` 启动时给出的两个来源（中文全译本 + 译本仓库）没有附带任何学习目标；被问之后选择了**系统设计面试 / 架构评审**这个方向，而不是「读通全书」或「自己实现存储引擎」。这条选择决定了后面所有课程的落点：每课必须产出一段**约束 → 选型 → 放弃的不变式 → 失效影响 → 监控指标**的陈述，而不是知识点罗列。

**Implications**：第 4 章（存储与检索）和第 10 章（一致性与共识）只讲到能判断「选谁、代价是什么」为止，不讲 LSM / Raft 的实现细节；练习一律是「给你一段架构描述，指出最可能崩的三处」，不做计算题。
